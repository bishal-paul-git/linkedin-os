# Approval Instructions

Approval is scoped permission for one external action or an explicitly defined batch.

## Default

Visible LinkedIn actions require approval.

## Exactness

Approval should bind to:

- target person/profile;
- action type;
- exact content where content exists;
- approval row/ID;
- approval time/scope.

If substantive content changes after approval, require new approval.

## No standing permission

Approval for one action or batch does not become permanent authorization.

## Execution

Approval only makes an action eligible. Run Control, current relationship state, idempotency, and security checks must still pass.
