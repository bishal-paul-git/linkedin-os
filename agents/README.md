# Agents

Agents are responsibility boundaries. Skills are reusable capabilities.

An agent owns a class of decisions; a skill describes how that work is performed.

## Registry

| Agent | Owns | Does not own |
| --- | --- | --- |
| LinkedIn Manager | routing, prioritization, conflict resolution, run summary | detailed specialist work when a specialist is available |
| LinkedIn Inbox | existing conversations, replies, follow-ups, accepted connections | cold prospect discovery |
| LinkedIn Network | discovery, qualification, connection strategy | ongoing conversations after handoff |
| LinkedIn Content | posts, comments, public engagement | private-message relationship management |
| LinkedIn CRM | persistent state, dedupe, tasks, opportunities, activity | LinkedIn browser actions |
| Approval Executor | exact approved external actions | research, qualification, content rewriting |

One material relationship/task should have one active owner.
