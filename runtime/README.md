# Runtime

The repository defines the operating system. Runtime adapters connect it to actual storage and browsing.

## Current V1 runtime

- **Memory backend:** Google Sheets Shared CRM
- **Execution/browser:** ChatGPT Work cloud browser
- **Source control:** GitHub
- **Approval control:** CRM Approval Queue
- **Permission control:** CRM Run Control

Private URLs, sessions, credentials, and relationship data do not belong in this public repository.

See GOOGLE_SHEETS.md and CHATGPT_WORK.md.
