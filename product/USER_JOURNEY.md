# User Journey

## New user

1. Sign up.
2. Create workspace.
3. Connect LinkedIn identity.
4. Connect CRM/data sources.
5. Configure goals/ICP/style.
6. System detects capabilities.
7. Run read-only health check.
8. Enable desired workflows.

## Daily experience

The user sees one operational dashboard:

- inbox items;
- people to connect with;
- accepted connections;
- suggested DMs;
- comments to approve;
- opportunities;
- follow-ups;
- blocked actions;
- integration health.

## Approval experience

Every external action shows:

- who;
- why;
- exact content;
- execution method;
- capability source;
- risk/blocker;
- approve / reject / edit.

If the action is assisted/manual, approval produces a “Complete on LinkedIn” step rather than pretending the system can send it.

## After action

The system reconciles the outcome and updates memory only after success is confirmed.
