# ChatGPT Work Launch

Use the LinkedIn OS skill/instruction files as operating rules.

Connect your private Shared CRM separately. Do not hard-code private CRM URLs into this public repository.

## First run

Start in **Stage 1 — Read Only**.

Before browsing LinkedIn:

1. Read `Config`.
2. Read `Run Control`.
3. Read `Agent Registry` if present.
4. Treat Run Control as authoritative.

Then:

- open LinkedIn using the authorized cloud-browser session;
- review unread messages first;
- review recent conversations that plausibly need action;
- read enough history to understand the relationship;
- check CRM state before treating someone as new;
- classify important conversations;
- detect reply needs, opportunities, meetings, unfinished follow-ups, commitments, and meaningful accepted connections;
- prepare natural reply drafts;
- write factual CRM state where permitted.

During Stage 1 do **not** send messages, send/accept/decline connection requests, comment, react, publish, or modify the LinkedIn profile.

If LinkedIn shows CAPTCHA, identity verification, unusual activity, restrictions, or security warnings, stop the affected workflow.

## Expected output

### DO NOW
Immediate relationship or conversation issues.

### APPROVAL NEEDED
Drafts or proposed external actions.

### OPPORTUNITIES
Sales, partnership, referral, meeting, or other meaningful signals.

### FOLLOW UPS
Relationship follow-ups with a genuine reason.

### WATCH
Relevant items not requiring action yet.

### NO ACTION
Reviewed items that need nothing.

### SYSTEM CHECK
Report whether LinkedIn navigation, conversation-history reading, CRM reads/writes, and browser reliability are sufficient to move to the next stage.

Do not advance Run Control automatically.
