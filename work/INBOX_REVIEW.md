# Inbox Review

Use LinkedIn Manager + Inbox + CRM.

1. Read Config and Run Control.
2. Review unread messages first.
3. Review recent conversations likely to need action.
4. Read enough history to understand the relationship, ask, promise, objection, or meeting context.
5. Check CRM before treating anyone as new.
6. Classify material conversations.
7. Update concise factual CRM state.
8. Draft replies only when a reply is actually useful.
9. For any proposed send, create a REPLY_DM or SEND_DM Approval Queue row when external sending is approval-gated.
10. Do not send unless a separate approved execution is allowed.

Return:

DO NOW / APPROVAL NEEDED / OPPORTUNITIES / FOLLOW UPS / WATCH / NO ACTION / BLOCKERS.
