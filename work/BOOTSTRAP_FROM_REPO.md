# Bootstrap LinkedIn OS From This Repository

Use this repository as the canonical LinkedIn OS operating manual.

Read in this order:

1. `SYSTEM.md`
2. `instructions/MASTER_INSTRUCTIONS.md`
3. `instructions/RUN_CONTROL.md`
4. `instructions/APPROVALS.md`
5. `SECURITY.md`
6. the relevant agent file under `agents/`
7. the relevant skill under `skills/`
8. the relevant workflow under `workflows/`
9. the corresponding execution prompt under `work/`

Then connect to the private Shared CRM and read:

- Config
- Run Control
- Agent Registry
- relevant relationship records
- Approval Queue

The repository defines behavior. The private CRM defines live state.

Do not copy private credentials, CRM records, LinkedIn messages, or session data into the public repository.
