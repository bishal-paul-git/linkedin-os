# Accepted Connection and DM

Input: contacts with `network_state=INVITED`.

Flow:

`reconcile connection state → positive acceptance evidence → network_state=CONNECTED → relationship_stage=ENGAGED → recover targeting/history → choose next action`

Possible next actions include no message, content-first engagement, introduction, contextual question, partnership/business discussion, or continuation of an earlier thread.

If a DM is appropriate:

`draft → SEND_DM/PENDING approval row → human decision → executor → verified send → relationship_stage=ACTIVE or ENGAGED depending on response context`

Never auto-pitch every accepted connection.

A connection becoming CONNECTED does not automatically create an opportunity.
