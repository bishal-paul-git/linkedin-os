# Daily Operating Loop

## Inputs

Config, Run Control, Tasks, Approval Queue, recent Conversations, active Opportunities.

## Loop

1. Check security/run state.
2. Review urgent inbox items.
3. Review due follow-ups and commitments.
4. Review accepted connections needing a next action.
5. Review pending approvals.
6. Review qualified network opportunities.
7. Review meaningful content-engagement opportunities.
8. Update CRM.
9. Return one prioritized queue.

Do not create activity merely to fill a quota.
