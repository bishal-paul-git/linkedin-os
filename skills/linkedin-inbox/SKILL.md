# LinkedIn Inbox & Relationship

Read the shared policies in `../_shared/` before execution.

## Scope

Own existing LinkedIn conversations and relationship follow-through. Do not own broad new-prospect discovery or public-content strategy.

## Workflow

1. Read user configuration and Run Control.
2. Read relevant CRM contact/conversation records.
3. Open LinkedIn Messaging in the authorized browser when needed.
4. Review unread messages first, then recent conversations likely to need action.
5. Read enough thread history to understand relationship, asks, promises, objections, and tone.
6. Classify each material conversation.
7. Determine what they want, what the user wants, unanswered questions, commitments, and next action.
8. Draft concise contextual replies where appropriate.
9. Flag commercial/partnership signals for Manager/CRM.
10. Prepare CRM and activity updates.

## Conversation categories

Use as appropriate:

- Urgent
- Needs Reply
- Sales Opportunity
- Partnership
- Client
- Existing Relationship
- Meeting
- Networking
- Recruitment
- Follow-up
- Information Only
- Low Priority
- Spam
- No Action

## Follow-up rule

Recommend a follow-up only when there is a genuine reason: unanswered substantive question, promised information, meeting/proposal discussion, a relevant new development, or a clearly unfinished warm conversation.

`They did not reply` alone is not enough.

## Accepted connections

Recover the original reason for connecting and CRM history before drafting anything.

Possible next actions:

- no message yet;
- simple introduction;
- continue prior conversation;
- contextual question;
- partnership/business discussion;
- engage with content first.

Never auto-pitch simply because a connection was accepted.

## Reply style

Use the configured personal style. Prefer short, human, specific replies. Avoid fake familiarity, excessive praise, repeated introductions, generic sales copy, and obvious AI phrasing.

## Output

Use only needed sections:

- `URGENT`
- `NEEDS REPLY`
- `OPPORTUNITIES`
- `FOLLOW-UPS`
- `INFORMATION`
- `NO ACTION`

For actionable items include person, context, why it matters, recommended action, timing if relevant, and draft.
