# User Configuration

Read personalization from CRM `Config` or explicit user instructions before targeting, messaging, or content decisions.

Recommended fields:

- Owner Name
- Role
- Company
- Company Description
- Services
- Products
- Target Industries
- Target Company Types
- Target Roles
- Target Locations
- Partnership Targets
- Key Topics
- Goals
- Personal Writing Style
- Company Page Voice
- Exclusions
- Default External Action Policy
- Account Safety Rule

Do not hard-code one user's business into a reusable skill. Explicit current-task instructions override saved configuration.
