# Browser Operating Rules

Use an authorized LinkedIn browser session when website access is required.

- Stop for user-controlled sign-in, 2FA, identity verification, payment, or secure checkpoints.
- Never request or expose passwords, session cookies, or authentication secrets.
- Read enough surrounding context before acting.
- Prefer exact profile/conversation URLs in CRM references.
- If a browser feature is unavailable, report the limitation rather than inventing an API capability.
- Never use browser automation to evade LinkedIn restrictions.
