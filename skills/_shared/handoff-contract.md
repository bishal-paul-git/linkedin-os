# Agent Handoff Contract

Every handoff must include enough context for the receiving workflow to act without reconstructing the relationship.

```text
CONTACT: [person]
COMPANY: [company]
FROM: [skill/agent]
TO: [skill/agent]
RELATIONSHIP: [type]
CURRENT STATUS: [status]
CONTEXT: [factual summary]
LAST ACTION: [action]
USER APPROVAL: [none / pending / approved + scope]
NEXT ACTION: [recommended action]
PRIORITY: [P0-P4]
DEADLINE: [if applicable]
SOURCE: [profile/conversation URL]
NOTES: [important caveat]
```

Never hand off only a name.
