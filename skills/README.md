# Skills

The repository keeps common policies in `skills/_shared/` so they are easy to maintain.

Each specialist skill should read the shared policies before execution:

- `user-config.md`
- `crm-schema.md`
- `approval-policy.md`
- `approval-queue.md`
- `handoff-contract.md`
- `linkedin-safety.md`
- `browser-rules.md`
- `run-control.md`

For a standalone packaged skill, copy these shared files into that skill's local `references/` directory and update paths accordingly.

Use `linkedin-manager` as the default entry point for broad LinkedIn work.
